# Vault externo

Este PoC usa **Vault externo** (ya desplegado fuera del clúster).

## Requisitos mínimos
- Endpoint y CA disponibles
- Auth Kubernetes habilitado en Vault
- Policies y roles creados por namespace (apim-wso2 / apim-gravitee)

## Nota
No se despliega Vault en este clúster. Los manifests aquí son solo referencia.
